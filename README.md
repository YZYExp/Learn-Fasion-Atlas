# 衣着有名：服饰风格、单品与穿着知识

面向非专业兴趣读者的中文图解服饰知识读本。内容从服饰风格与文化背景出发，进入单品名称、衣物结构、材料、装饰、配饰和现实穿着；认识名称，也理解衣物各部分怎样共同发挥作用。

## 阅读入口

- [在线阅读](https://yzyexp.github.io/Learn-Fasion-Atlas/)：分类图鉴、分章正文与穿着观察。
- [全书合并稿](book.md)：连续阅读的 Markdown 主稿。
- [完整 PDF](output/pdf/fashion-atlas-expanded.pdf)：含目录、书签与就近资料链接。
- [男性服饰分册](output/pdf/menswear-atlas.pdf)：第32—39章。
- [单品、结构与材料分册](garment-details.md)：从第13章进入单品知识。

当前为39章正文、导读及5篇附录；91张配图，全书227页。

## 全书主线

风格与文化背景 → 常见单品 → 领袖、材料与结构 → 传统和角色服装 → 纹样、配饰与衣物组合 → 男装及现实场景。第11章讲资料阅读，第20章整合辨识方法，第39章讨论天气、活动和着装要求。

本版已逐章订正以图像创作为中心的叙述。正文直接解释现实服饰知识，练习用于观察、比较和理解穿着；图像创作仅在附录末作为延伸用途提及。图片样本数不构成分类上限。

## 构建与校验

章节主稿在 `chapters/`，附录在 `appendices/`；章节顺序与标题由 `book.json` 维护。

```bash
python3 scripts/build.py
python3 scripts/build.py --check
python3 scripts/integrate_expanded_cards.py --check
```

导出全书、章节与男装 PDF：

```bash
python3 -m pip install -r requirements.txt
export FASHION_ATLAS_FONT=/absolute/path/to/NotoSansSC-Regular.ttf
export FASHION_ATLAS_JPEG_QUALITY=65
python3 scripts/export_pdf.py
python3 scripts/split_pdf.py
```

PDF 导出需支持中文的常规字重 TTF；原始 PNG 保留在工程中，PDF 使用压缩图片以控制体积。

构建网站：

```bash
python3 -m pip install -r web/requirements.txt
python3 web/build_content.py
python3 web/build_thumbnails.py
python3 web/check_site.py
```

推送 `main` 后由 GitHub Actions 校验并发布 GitHub Pages。网页流程复用已导出的 PDF，不在发布时重新排版全书。历史修订见 [CHANGELOG.md](CHANGELOG.md)，项目覆盖与完成记录见 [PROJECT.md](PROJECT.md)，协作约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。
