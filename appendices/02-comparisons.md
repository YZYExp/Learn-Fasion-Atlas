# 附录 B｜相邻风格的联系与区别

服饰风格常共享单品，也会随时代、地区和社群实践变化。以下十二组比较整理正文中的主要关系：有的区别在文化背景，有的区别在衣物结构，还有的只是当代审美标签的侧重点。它们不是用一件配饰就能判定的互斥类别。

## 01｜Ivy 与 Preppy：共享学院衣橱的不同侧重

两者都与学院衣橱相关，常见扣领衬衫、针织衫、夹克、卡其裤与休闲皮鞋。Ivy 的讨论常着重这些单品形成的衣橱传统；Preppy 的日常使用则常包括较鲜明的色彩、格纹与运动休闲细节。自然肩夹克与扣领衬衫可以同时进入两种搭配，裙装和裤装也不是二者的分界。

比较一套穿着时，衣物组合比单件名称更有用：灰褐夹克、浅色衬衫和卡其裤，与藏蓝夹克、鲜色针织和格纹下装，呈现出不同的色彩重心，但仍可能共享学院服饰背景。[相关知识与案例](../chapters/02-classic.md)

## 02｜暗黑学院与浪漫哥特：文化联想与材料组织

暗黑学院是当代审美标签，常把深色粗花呢、马甲、长外套和书包等与阅读、校园生活的想象联系起来。浪漫哥特属于更广的哥特服饰领域，蕾丝、绒面、高领、修长裙线与装饰吊坠是其中一条常见路径。

深色本身不足以区分二者。粗花呢夹克与衬衫形成的层次，和大面积绒面长裙与蕾丝形成的层次，在材料、比例及文化参照上都不同；真实穿搭也可以同时借用两边的元素。[学院审美](../chapters/02-classic.md)／[哥特服饰](../chapters/04-street.md)

## 03｜Cottagecore 与 Mori kei：田园生活想象与柔软层叠

Cottagecore 常借围裙、花卉、格纹和乡间劳动衣物，形成对田园生活的当代想象；Mori kei／森系则常见自然低对比色、宽松罩衫、针织与错落下摆。两者可共享棉布、蕾丝与草编配饰，却不必有相同的轮廓。

围裙腰线和上下分段会加强腰部位置；宽松罩衫与多层下摆则可能弱化腰线，让层次沿身体向下延伸。这个区别有助于认识两种常见搭配方向，但不构成所有款式的硬性规则。[相关知识与案例](../chapters/03-romantic.md)

## 04｜Boho 与 Hippie 灵感：当代语汇与具体年代参照

刺绣、流苏、宽松衣物、喇叭裤与绒面配饰，可以在两种穿搭里出现。Boho 在当代时尚语境中使用较广；Hippie 灵感则进一步指向历史文化参照，需要结合时期、地区和具体衣物理解。

一件刺绣上衣与现代直筒裤的组合，可以采用 Boho 语汇；当喇叭裤、绒面背心及整套比例都指向某一时期时，年代关系更明确。流苏包单独出现，不能说明整套穿着的历史背景。[Boho](../chapters/03-romantic.md)／[年代与 Hippie 灵感](../chapters/06-retro.md)

## 05｜Coquette 与 Sweet Lolita：装饰语汇与服饰体系

蝴蝶结、珍珠、蕾丝和浅色是二者可能共享的元素。Coquette 在本书作为当代轻甜装饰审美的入口；甜系洛丽塔还涉及裙型、衬裙体积、上身结构，以及头饰、袜鞋之间的协调。

因此，日常中长裙即使有小蝴蝶结，也不能仅据此归为洛丽塔。辨认甜系洛丽塔时，整套衣装关系和社群语境比某一处“甜”的装饰更重要。[轻甜装饰审美](../chapters/03-romantic.md)／[洛丽塔体系](../chapters/07-lolita.md)

## 06｜Goth 与 Gothic Lolita：文化领域与其中相邻的衣装形式

Goth／哥特服饰内部有多种路线，修长黑裙、蕾丝与绒面只是浪漫哥特的一种常见呈现。Gothic Lolita／哥特洛丽塔则同时保留洛丽塔的裙体与协调方式，并运用哥特相关的色彩或装饰语言。

黑色长裙与具有衬裙体积的洛丽塔裙装，不能仅按颜色合并；同样，裙长也不足以决定二者的归属。识别时需要把服装结构、整套搭配与文化背景放在一起。[哥特服饰](../chapters/04-street.md)／[哥特洛丽塔](../chapters/07-lolita.md)

## 07｜Punk 与 Grunge：改造、装饰与松旧层次

二者都可能出现破损格纹、牛仔与靴子。朋克服饰中的金属、皮革、拼接和破坏处理，常形成较明显的对立关系；Grunge 常借褪色格衬衫、宽松牛仔裤与磨损衣物，形成松弛的层叠。

这些是观察衣装的入口，不能代替音乐与社群背景。衣物整洁与否也不能用来判断一个人是否属于某个社群。[相关知识与案例](../chapters/04-street.md)

## 08｜Workwear 与 Techwear：劳动衣物与技术系统

Workwear／工装以劳动衣物为重要来源，厚帆布、牛仔、外贴袋与劳动夹克是常见线索。Techwear／技术服装与机能语汇则常关注活动裁片、袋位、携带系统和材料性能之间的配合。

两者都可能有多个口袋，但数量不是决定条件。贴袋如何容纳物品、衣片是否方便活动、闭合是否适合环境，比“口袋多”更接近功能分析；耐磨、防水与防护等性能还需要材料或产品资料支持。[相关知识与案例](../chapters/05-functional.md)

## 09｜Gorpcore 与 Athleisure：户外装备与训练衣橱的日常化

Gorpcore／城市户外审美常组合外壳夹克、抓绒、徒步裤、背包和越野鞋；Athleisure／运动休闲则常把训练上装、运动裤、打底衣物与跑鞋带入日常穿着。

两者能在同一套衣服里交叉。外壳与徒步裤主导时，户外装备关系更明显；运动上装与训练裤主导时，训练衣橱的来源更明显。普通城市搭配采用某种装备外观，并不意味着适合对应的专业活动。[相关知识与案例](../chapters/05-functional.md)

## 10｜洛可可、高腰摄政与后裙撑：裙体体积的位置

这组三向比较有助于理解不同时期服饰的轮廓差异。正文选取的洛可可灵感案例着重侧向展开的裙体；摄政／帝政相关案例着重胸下高腰与较纵向的裙线；后裙撑案例则把较多体积集中在裙体后方。

腰线、支撑与体积位置不能用“大裙摆”一词概括。历史服装的完整辨识仍需要时期、地区、场合及藏品资料；这些简化轮廓是阅读历史案例的起点。[年代、结构与藏品案例](../chapters/06-retro.md)

## 11｜汉服、旗袍与新中式：形制、衣物与当代借用

汉服涉及多种历史形制及当代穿着实践；旗袍是一类具有时期与版型差异的衣物；新中式则是当代设计与搭配中的宽泛标签，常把传统细节用于现代衣橱。三者不是同一层级的三个互斥类别。

例如，带立领和盘扣的现代短夹克，可以体现新中式设计，却不能仅凭这两个细节判定为某一朝代的服装复原，也不能直接归为旗袍。衣长、衣片、领襟和整套组合仍需具体核对。[传统、改良与当代设计](../chapters/08-tradition.md)

## 12｜极简、解构与雕塑感：信息量、结构和体积

极简着重减少视觉竞争的方式；解构着重既有衣物结构、里外关系或完成方式如何被重新组织；雕塑感着重衣物在身体周围形成的体积。一件白色外套可以同时少装饰、采用错位门襟，并在肩部形成显著体积。

因此，它们可以共同描述一件衣服的不同方面，无需强行只选一个名称。进一步比较时，应分别考察配色与装饰密度、裁片与接合关系、体积位置及支撑方式。[相关知识与设计案例](../chapters/09-avant.md)

以上是正文知识的比较索引。各章的博物馆藏品、机构资料与社群研究链接，提供更具体的时期、对象与语境；观察线索用于帮助比较，不代替这些来源。
