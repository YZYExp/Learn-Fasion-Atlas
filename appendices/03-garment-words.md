# 附录 C｜从衣物到细节：84 条双语查词表

本表整理第 13—20 章涉及的衣物、材料与结构名称，按部位分组。简短释义用于查词，具体构造、用途和相邻类别的区别见对应章节。它不是互斥分类：一条裙可以同时是 A 字、百褶、中长、带蕾丝边；一个袖子也可以同时采用插肩连接和主教袖体。

## 从日常称呼到衣物结构

日常称呼往往把材料、衣型和风格合在一起。下面以常见说法为入口，说明它可能涉及的结构；辨识时仍应以具体衣物为准。[综合辨识见第 20 章](../chapters/20-description-workshop.md)。

| 日常称呼 | 需要区分的知识 |
|---|---|
| 蕾丝裙 | 蕾丝可以是沿领缘或裙摆的窄条镶边、局部接片，也可以满幅覆盖衣身；是否带衬里是另一项结构信息。 |
| 内衣感的裙子 | 衬裙式外穿连衣裙常借用细肩带与简洁垂坠线条；它与内层衬裙的区别还涉及材料、裁剪和用途。 |
| 运动裙 | 网球连衣裙、独立半裙与带短裤结构的裙式短裤不是同一衣型；内置配置以实物或产品资料为准。 |
| 鼓起的袖子 | 泡泡袖、主教袖等可在不同部位聚集布量；袖长、收口和装袖方式仍可分别辨认。 |
| 领口堆着布 | 垂褶领口用额外布量形成悬垂，与单独围巾或固定领片的结构不同。 |
| 腰上有褶皱 | 抽褶把布量聚集在局部；褶裥以折叠组织布量；自然受压皱褶未必是设计结构。 |
| 宽裤子 | 阔腿指松量与宽度，直筒、锥形和喇叭则说明裤管宽度变化；这些名称可以交叉。 |
| 很短的小外套 | Bolero 与 shrug 都可能作为短外搭，但衣身覆盖、袖体和前开方式需要具体比较。 |
| 蓬松的裙摆 | 裙摆体积可来自圆裁、插片、抽褶、分层或内层支撑，不能仅凭蓬松程度确定做法。 |
| 背部有弹性小褶 | 多排弹性抽褶可以让布面收缩并产生伸展余量；普通平行缝线与无弹性褶饰不一定有同样作用。 |

掌握术语的价值在于把衣服的各项特征分开理解：材料不等于衣型，衣型不决定全部用途，外轮廓也不直接说明纸样。遇到陌生款式，先查对应部位，再比较相邻结构，比一次记住全部英文词更有帮助。
