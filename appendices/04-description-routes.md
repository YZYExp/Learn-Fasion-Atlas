# 附录 D｜从模糊印象找到准确说法

先找你看见的对象，再查细节。一个模糊词往往同时包含衣型、材料、年代与气氛；不必一次猜中风格名。本附录给检索路线，基础双语定义仍查[附录 A](01-glossary.md)与[附录 C](03-garment-words.md)。

## 把查到的词接起来

| 要表达的关系 | 常用检索词 | 组合时补什么 |
|---|---|---|
| 图案的组织 | repeat 重复、scale 尺度、placement 定位 | 图案大小、疏密、方向、出现部位 |
| 帽子的外轮廓 | crown 帽冠、brim 帽檐 | 冠高、檐宽、边缘走向与佩戴位置 |
| 首饰的位置 | stud 耳钉、drop earring 垂坠耳环、brooch 胸针 | 位置、尺寸、数量与表面光泽 |
| 叠穿的关系 | base layer 基础层、mid layer 中间层、outer layer 外层 | 谁在谁外面、哪里露出、怎样开合；功能层与可见层的区别见[第 31 章](../chapters/31-context-layering.md) |
| 场景的要求 | dress code 着装要求、occasion 场合 | 邀请方原词、活动与室内外条件；场景与实际要求的区别见[第 31 章](../chapters/31-context-layering.md) |

不要把查词结果写成孤立标签串。先用[第 20 章](../chapters/20-description-workshop.md)的槽位组织成句，再用[第 11 章](../chapters/11-express.md)的方法转成检索词或生图 brief。例如“复古碎花感”可以展开为“米白底小型蓝花重复纹样，方领收腰连衣裙，裙长至小腿中部，领缘窄饰边，配棕色低跟玛丽珍鞋”。若仍不能确认领型或材料，就保留更宽的可见描述，回到相邻类别比较；查词的目标是减少歧义，不是给每件衣服强行贴上唯一名称。


## 一次只解决一个不确定点

如果你既不认识衣型，也说不清材质，先找衣物边界：上衣与裙子是否分开、裤子是否有两条裤腿、肩上靠带子还是领口固定。第二次再补长度和轮廓，第三次才加表面、图案和配饰。无法确定的内容可以写成“带缎面光泽”“皮革感表面”或“汉服灵感层叠袍服”，不要把视觉相似扩大为成分、性能或历史形制结论。保存最终描述时，同时留下你核对过的参考图与资料，下一次修改便能知道哪些是观察、哪些是创作选择。
